# Legacy

MVP 스코프 재정의로 도메인 모델이 바뀌면서(게이트·리뷰·주제·레퍼런스·관계 changeset이 빠지고 캡처 → 다이제스트 → 진술 → 연결만 남는다) 새 구현을 옆에 새로 세우기로 했다. 여기 있는 건 이전 세대 구현이다.

**읽기 전용 참고 자료다. 합칠 계획은 없다.** 새 구현이 필요한 만큼 대응물을 훑고 나면, 참고가 끝난 시점에 이 폴더는 통째로 삭제된다.

격리는 자동이 아니라 네 곳에 각각 걸어둔 결과다. pnpm 워크스페이스(`apps/*`, `packages/*`)와 `supabase/migrations` 밖이라 설치·빌드·타입체크가 안 걸린다. prettier(`.prettierignore`)·eslint(`eslint.config.js`)·knip(`knip.json`)은 워크스페이스가 아니라 파일 글롭으로 도는 도구라, 이 셋은 각각 `legacy/`를 명시로 뺐다. 나중에 파일 글롭으로 도는 도구를 하나 더 붙일 때 이 폴더를 빼는 걸 잊으면 조용히 다시 걸린다. 안에 tsconfig가 없어서 에디터에서 열면 타입이 안 잡혀 빨간 줄이 가득할 수 있다 — 참고는 검색·읽기로 한다.

이동 자체는 파일 내용을 건드리지 않은 순수 이동이라, 각 폴더 안 코드가 서로/외부와 참조하던 관계는 옮겨진 상태 그대로 깨져 있다(예: `apps/web`이 `apps/server`를 가리키던 workspace 의존성). 무해하다 — 아무도 이 경로에서 코드를 실행하지 않는다.

## 폴더

- **apps/server** — Fastify + tRPC 백엔드. 게이트·리뷰·주제·레퍼런스·관계 changeset을 포함한 이전 세대 도메인 전체(라우터·서비스·인프라·프롬프트)가 여기 있다.
- **apps/web** — React + TanStack 프론트엔드. 이전 세대 화면·기능(계정·인증·인테이크·알림·온보딩·프로필·PWA·실시간·레퍼런스·리뷰·설정·워크스페이스) 전체.
- **apps/mcp** — 외부 AI가 원격 MCP로 nema에 닿는 레일. 도구 정의와 tRPC 클라이언트 연동.
- **packages/shared** — 프론트·백엔드가 공유하던 zod 스키마와 타입(구 도메인 모델 기준).
- **supabase/migrations** — 이전 스키마의 마이그레이션 141개. 새 스키마는 `supabase/migrations`(워크스페이스 안, 이 폴더 밖)에서 새 줄로 시작한다.

## 찾는 법

폴더별 전수 인벤토리는 여기 없다 — 만드는 시점엔 나중에 뭐가 필요할지 모르는 채로 쓰게 되고, 리포에 이미 실패 선례가 있다(`docs/archive/save-engine-v1/removed-code-inventory.archive.md`: 실제로 다시 꺼내 쓸 때 필요했던 건 목록이 아니라 원본을 가리키는 포인터였다). 이 폴더는 코드 자체가 그대로 남아 있으니 포인터도 필요 없다 — 특정 동작이 옛날엔 어떻게 처리됐는지 궁금하면 이 폴더 안에서 바로 검색·열람하고, 새 구현에 무엇을 왜 가져왔는지는 PR에 남긴다(루트 `CLAUDE.md` 참고).
