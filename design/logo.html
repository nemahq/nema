Core — 매일 쓰는 기본

사용자가 가장 자주 접하는 2종. 여기에 브랜드 정체성이 집중된다.

01 · PRIMARY ★
Dark + Teal
앱스토어, iOS/Android 홈화면, PWA manifest, GitHub 조직 프로필, 소셜 미디어 프로필. Nema의 얼굴.
02
Light + Teal
라이트모드 앱 내부. 사이드바 로고, 문서 헤더, 웹사이트 네비게이션. 화이트 배경 위에서 브랜드 컬러 유지.

Monochrome — 단색이 필요할 때

브랜드 컬러를 쓸 수 없는 환경을 위한 대체 버전. 자주 쓰이지 않는다.

03
Dark + White
단색 인쇄, 흑백 문서, teal을 렌더링할 수 없는 환경. 브랜드 컬러를 희생하더라도 정체성 유지가 필요할 때.
04
Light + Dark
Android 적응형 아이콘(라이트 테마 변종), 시스템이 강제로 흑백 아이콘을 요구하는 맥락.

Experimental — 특수 맥락에서만

디자인 시스템 밖의 확장. 일회성 자료나 브랜드 스테이트먼트가 필요할 때. 일상적으로 쓰지 않는다.

05
Teal gradient bg
랜딩 페이지 히어로, OG 이미지, 소셜 커버. 브랜드를 "풀 임팩트"로 보여주는 유일한 teal 배경 버전.
06
Gradient mark
발표 자료, Product Hunt 배너, 일회성 프로모션. 시각적 풍부함이 필요한 맥락. 작은 사이즈에는 부적합.
07
White→Teal mark
브랜드 스토리텔링, 컨셉 설명 자료. "실이 바늘귀를 통과한다"는 메타포를 시각적으로 표현할 때.
08
Teal→Dark bg
앱 내 스플래시 화면, 온보딩 플로우 배경. 다크 환경으로 자연스럽게 전환되는 프리미엄 느낌.

Mark + Wordmark

Satoshi Bold, Pascal case "Nema". Mark과 텍스트 조합.
