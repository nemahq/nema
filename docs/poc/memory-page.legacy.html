맵 뷰 — 구현 시 추가 필요 사항
1. Glow / 블룸 효과
각 노드 뒤에 타입 색상의 은은한 radial gradient glow. 노드가 "빛나는" 느낌을 줘서 다크 배경 위에서 시각적 깊이감 형성.
Sigma 커스텀 WebGL 노드 프로그램 → fragment shader에서 distance-based alpha gradient 적용
2. Semantic Zoom (노드 렌더링 전환)
줌 레벨에 따라 노드 렌더링 자체가 변화. 줌아웃: 색상 점만 → 중간: 점 + 라벨 → 줌인: 상세 카드 (타입 아이콘, 기록 수, 활동 바). 현재는 라벨 표시/숨김만 동작.
camerastateUpdated 이벤트 → ratio 기준으로 3단계 WebGL 노드 프로그램 교체. 각 단계별 커스텀 NodeProgram 구현
3. 클러스터 경계 시각화
같은 타입 또는 밀접하게 연결된 노드 그룹 주변에 은은한 배경 영역 표시. 사용자가 "이쪽이 하나의 덩어리구나"를 직관적으로 인식.
graphology community detection (Louvain) → 클러스터별 convex hull 계산 → beforeRender 훅에서 canvas로 반투명 영역 렌더링
4. 개요 ↔ 맵 전환 애니메이션
개요(칩)에서 맵(그래프)으로 전환 시 칩이 노드 위치로 이동하며 모핑. 두 뷰가 같은 데이터의 다른 표현이라는 걸 시각적으로 전달.
FLIP 애니메이션 패턴. 칩 DOM 위치 → 그래프 노드 좌표 매핑 → transform 애니메이션 → sigma 렌더링 전환
5. 스크롤 이벤트 분리
맵 위에서 일반 스크롤이 줌으로 처리되는 문제. Ctrl/Cmd+스크롤 또는 핀치만 줌으로 처리하고, 일반 스크롤은 무시.
React 컴포넌트에서 wheel 이벤트 인터셉트. ctrlKey/metaKey 체크 후 sigma에 전달 여부 결정
6. 접근성 (키보드 네비게이션)
Tab으로 노드 간 이동, Enter로 선택, Escape로 선택 해제. 스크린 리더를 위한 ARIA 라벨. 시각 장애 사용자를 위한 고대비 모드.
React 컴포넌트에서 ARIA role="application" + aria-label per node. 커스텀 키보드 핸들러: Tab → 다음 노드 포커스, Enter → selectEntity, Esc → 해제
7. 엣지 커브
직선 엣지가 딱딱함. 부드러운 커브 엣지로 "지식이 흐르는" 유기적 느낌. 연결이 겹칠 때 구분도 쉬워짐.
Sigma 커스텀 EdgeProgram 구현. quadratic bezier curve를 WebGL로 렌더링. control point는 엣지 중점에서 법선 방향으로 offset
8. 호버 라벨 다크 배경
현재 호버 시 라벨 배경이 밝은색(Sigma 기본값). 다크 테마에서 라벨이 붕 뜨는 느낌. Stone-800 배경 + 밝은 텍스트로 통일.
Sigma defaultDrawNodeHover 커스텀 함수 구현. 라벨 배경 roundedRect를 Stone-800로 채우고 텍스트를 fg-primary로
9. 챗 컴포저 AI 응답
현재 텍스트 매칭만. "채널톡 관련 인물 보여줘", "Kyle에서 Neo4j까지 경로" 같은 자연어 질의를 맵 액션으로 변환.
LLM에 graphology 기반 도구 제공 (neighbors, shortestPath, community). LLM이 도구 호출 → 결과를 팝오버 + 맵 하이라이트로 렌더링
10. 카메라 애니메이션
노드 클릭, 탐색 경로 클릭, 검색 결과 클릭 시 해당 노드로 부드럽게 카메라 이동 + 줌인. PoC에서 Sigma CDN의 camera.animate 좌표계 문제로 미구현.
Sigma camera.animate({x, y, ratio}, {duration}). 좌표는 graph space vs viewport space 변환 필요. @react-sigma에서는 useCamera 훅으로 제어
11. 노드 호버 시 엣지 관계 라벨
노드 호버 시 연결 엣지의 관계 유형(소속, 리드 등)을 한꺼번에 표시. 현재는 엣지 개별 호버에서만 보임. 연결이 많은 노드에서는 라벨이 겹칠 수 있으므로 조건 처리 필요 (N개 이하만 표시).
nodeReducer에서 hoveredNode의 connectedEdges를 순회, 각 엣지의 rel 속성을 Sigma edgeReducer에서 label로 표시. labelRenderedSizeThreshold로 밀도 제어
12. 생각의 변화 — 추가 인사이트 유형
현재 PoC에 구현된 인사이트: 전환점(⚡), 생각 변화(🔄), 언어 변화(💬), 반복 패턴(🔁), 확신도(📊). 추가로 구현할 유형:
• 영향 귀인 — 어떤 외부 입력이 생각을 바꿨는지 인과관계 추적. 기록 저장 시점과 의견 변화 시점 상관분석
• 사고 스타일 프로필 — 결정 속도, 정보 수집 패턴, 수정 빈도를 종합한 동적 프로필. 월간 업데이트
• 갈림길 기록 — 거절된 대안을 보존, 새 증거 누적 시 재검토 제안
• 감정 톤 추적 — 기록의 언어 톤에서 불안/확신/중립 추출, 감정 변화와 결정 품질 상관관계
• 잊힘 지도 — 한때 활발했으나 완전히 사라진 지식 클러스터 시각화
• 서사 공유 — 학습 여정을 깔끔한 글로 내보내기 (온보딩, 블로그, 바이럴 훅)
13. 챗 컴포저 응답 → 사이드 패널
하단 챗 컴포저에서 질문 시 응답이 사이드 패널에 표시. 노드 클릭, 기록 미리보기, 챗 응답이 모두 같은 사이드 패널을 공유. "오른쪽을 보면 답이 있다"로 통일.
사이드 패널 상태 관리: { type: 'entity' | 'record' | 'chat', data: ... }. 챗 응답 시 패널 내용을 chat 타입으로 교체. 맵 하이라이트와 동기화
14. 빈 상태 — 축적 가치 예감 장치
데이터가 없거나 적을 때 "쌓이면 이런 모습이 될 거야"를 보여줌. 빈 페이지가 아니라 축적 동기를 부여하는 경험. 스켈레톤 맵(AI 생성 토픽 뼈대), 진행 표시("3개 더 기억하면 첫 연결이 생겨요"), 데모 미리보기 중 택일.
첫 기억하기 완료 시 structuring engine에서 추출된 엔티티로 스캐폴드 그래프 생성. 실제 데이터가 쌓이면 점진적 교체. Cold Start Scaffolding (Tier 3)
15. 개요↔맵 상태 동기화
기간 셀렉트 값, 선택된 엔티티, 사이드 패널 열림 상태, 렌즈 상태가 뷰 전환 시 일관되게 유지되어야 함.
React 상위 컴포넌트에서 공유 상태 관리. 뷰 전환은 렌더링만 교체, 상태는 유지
16. 모바일 반응형
맵 + 사이드 패널이 작은 화면에서 공존 불가. 모바일에서는 사이드 패널을 바텀시트로, 맵은 전체 화면으로. 개요 칩은 단일 컬럼으로 리플로우.
Tailwind breakpoint 기반. md 이하에서 사이드 패널 → 바텀시트 전환. 맵 타입 필터 → 접이식
17. 로딩/에러 상태
그래프 데이터 로딩 중 스켈레톤 표시. 로딩 실패 시 "다시 시도" 안내. 개요 칩도 로딩 중 스켈레톤.
TanStack Query suspense + ErrorBoundary. 스켈레톤은 weave Skeleton 컴포넌트 재사용
18. URL 딥링크
엔티티 선택 시 URL 변경 (/memory?entity=ai-mkt&view=map). 공유/북마크 가능. 홈페이지 인사이트 카드에서 기억 페이지 특정 클러스터로 바로 이동할 때도 사용.
TanStack Router search params. 뷰 모드, 선택 엔티티, 렌즈 상태, 기간을 URL에 반영
19. 키보드 단축키
Cmd+K → 챗 컴포저 포커스, Esc → 사이드 패널 닫기, Tab → 노드 간 이동 (접근성과 연결).
useRegisterAction 훅 활용. 기존 단축키 시스템과 통합
20. 노드 위치 영속성
새로고침/재방문 시 그래프 레이아웃이 동일하게 유지. 사용자가 "오른쪽 위에 있던 그 노드"라는 공간 기억을 쌓을 수 있어야 함.
ForceAtlas2 결과 좌표를 서버에 저장 (entity별 x,y). 재방문 시 저장된 좌표로 초기화, 새 노드만 FA2로 배치
