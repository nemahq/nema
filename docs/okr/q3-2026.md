# Q3 2026 OKR

**기간:** 2026-06-29 (W1) ~ 2026-09-27 (W13)

## O (Objective)

nema가 나 말고 남에게도 값을 하는지 확인한다.

## KR (Key Results)

- KR1: 대상 사용자 중 주 2회 이상 사용한 사람 ≥3명
- KR2: 그중 실제로 결제한 사람 ≥1명

## Initiative

**만들기**
- W4까지 MVP 출시
  - 목적: KR1·2를 볼 수 있는 전제조건. MVP가 없으면 리텐션 시계 자체가 안 켜진다.
  - 기준: [11-first-product-direction](../product/11-first-product-direction.md)

**사용자 구하기**
- W5까지 대상 사용자 ≥10명이 첫 맥락을 넣고 저장
  - 목적: KR1(3명 리텐션)을 달성하려면 깔때기 윗단이 충분히 넓어야 한다. 10명 중 3명이 남는다는 가정.
- W9까지 사용 후 피드백 인터뷰 ≥10회
  - 목적: 무엇이 값을 했는지, 뭐가 걸렸는지 파악해 KR1 달성을 막는 것을 제거한다.

**결제 전환**
- 일정량을 다 쓴 사용자에게 결제 제안 (W8부터)
  - 목적: 경험 없이 묻는 결제 의향은 평가(말)에 불과하다.
- 초기엔 수동 결제(계좌이체 등)로 수요 확인 → 요청이 쌓이면 결제 모듈 도입
  - 목적: 마찰이 있는데도 결제하는 사람이 진짜 수요를 증명한다.
  - 과금 방식(크레딧·구독·파일럿 등)은 사용 패턴 데이터 보고 결정
