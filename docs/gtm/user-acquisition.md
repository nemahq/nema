# 초기 사용자 확보 전략

> MVP 출시 후 첫 1주 안에 대상 사용자 10명을 확보하기 위한 실행 설계서. 누구를 찾고, 어떻게 첫 말을 걸 건지에 대한 기준을 정한다.
>
> 관련 문서: [Q3 2026 OKR](../okr/q3-2026.md)

## 1. 대상 — 통증 기준

이미 외부 LLM으로 일하며, 길게 끌고 가는 자기만의 결정 줄기를 자주 끊겼다 다시 잇는데, 다시 켤 때마다 "뭐가 있었는지조차 흐릿한" 통증을 겪는 사람.

이 기준은 직군 정의가 아닌 **판별 도구**다. 지인이든 낯선 사용자든 이 통증이 있는지를 기준으로 판별한다.

관련 문서: [첫 제품 방향](../foundations/11-first-product-direction.md)

## 2. 사용자 확보 구조

두 채널을 병행하되 역할을 분리한다.

**지인 경로**
채널톡 퇴사 시 창업 계획을 설명하고 약속을 받아둔 상태. 넓게 오픈해서 피드백·인터뷰 데이터를 빠르게 모으는 채널로 활용한다. 순차적으로 받는다(한꺼번에 받으면 피드백 소화가 안 되고, MVP 품질 확인 전에 나쁜 첫인상을 줄 수 있다).

**낯선 사용자 (커뮤니티)**
나를 모르는 사람이 통증만으로 오고 유지되면 그게 리텐션의 진짜 신호다. 지인만으로 리텐션을 재면 친목 효과와 구분이 안 된다.

**타이밍**
- MVP 출시 직후: 지인 2~3 + 낯선 사용자 2~3, 총 4~6명 (첫 배치)
- 출시 후 1주 내: 피드백 반영 후 나머지 추가 → 10명 채우기

## 3. 커뮤니티 접근 방법

제품을 앞세우지 않는다. 통증을 먼저 꺼내고, 반응하는 사람에게만 한 발씩 다가간다.

**진입 커뮤니티 (확정)**
- 더배러 — AI 네이티브·생산성 관심층 (오픈카톡 1,800명+)
- 지피터스 — AI 활용 실무자 집단
- 옵시디어너리 (네이버 카페) — 지식관리 도구 헤비유저

**3단계 — 단계별 투명도**

1. **문제 먼저 (커뮤니티)** — 통증 질문을 포스팅한다. 내 제품이나 창업 사실은 꺼내지 않는다. 공감·댓글로 반응하는 사람이 대상 신호.
2. **창업자 투명 (DM)** — 반응한 사람에게 직접 연락한다. 창업자 소개 + "30분 얘기 나눠볼 수 있을까요?" 제안. DM에서 통증 기준으로 판별하고, 맞으면 MVP 초대로 연결.
3. **여정 공유 (소셜)** — 커뮤니티 포스팅·DM과 병행해서 소셜 채널에 여정을 공유한다. 1·2단계에서 만난 사람들이 배경 맥락을 갖게 된다. 새로운 사람에게도 자연스럽게 닿는다.
