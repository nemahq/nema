# QA 체크리스트

> 기능 개발 진척 추적용. 체크 = 동작 확인 완료.

---

## 1. 인증

- [x] Google OAuth 로그인 → 메인 화면 진입
- [x] Magic Link(OTP) 발송 → 이메일 링크 클릭 → 로그인 완료
- [x] 새로고침 후 로그인 상태 유지
- [x] 로그아웃 → 로그인 페이지 리다이렉트
- [x] 미인증 상태에서 보호된 라우트 접근 → 로그인 페이지로 이동
- [x] 잘못된 이메일 입력 → 에러 메시지 표시

## 2. 세션 관리

**목록/생성**
- [x] 새 세션 생성 → 목록 최상단에 추가
- [x] 세션 목록 무한 스크롤 → 다음 페이지 로드
- [x] 세션 선택 → 해당 세션 채팅 화면으로 전환
- [ ] 첫 메시지 전송 후 → 세션 제목 자동 생성 ← **버그: 제목 미생성**

**이름 변경**
- [ ] 세션 이름 수동 편집 → 저장 후 목록 반영 ← 낙관적 업데이트 필요
- [x] 빈 이름 입력 방지

**삭제**
- [x] 세션 삭제 → 포커스된 세션이면 홈 이동, 아니면 현재 세션 유지
- [x] 삭제 확인 다이얼로그 표시

## 3. Put-in: 드래프팅 (Phase 1)

**기본 흐름**
- [ ] 정보 입력 후 전송 → 구조화된 드래프트 본문이 스트리밍으로 생성
- [ ] 드래프트 카드가 사이드 패널에 나타남
- [ ] 드래프트 카드 접기/펼치기 동작
- [ ] 드래프트 카드에 유사 문서 힌트 표시 (배경 검색 결과)

**수정 사이클**
- [ ] 드래프트 활성 상태에서 수정 요청 → 기존 본문 기반으로 재생성
- [ ] 여러 번 수정 요청 → 매번 최신 본문 반영

**취소**
- [ ] 드래프트 취소 요청 → 드래프트 카드 사라짐 + 세션 draft 초기화

**복합 시나리오**
- [ ] 드래프트 활성 중 pull-out 질문 → 답변은 채팅 버블, 드래프트 유지
- [ ] 새로고침 후 기존 드래프트 복원 (서버 사이드 영속화)

## 4. Put-in: 저장 (Phase 2)

**저장 흐름**
- [ ] 드래프트 저장 요청 → 드래프트 카드 사라짐
- [ ] 여러 주제가 섞인 입력 → 각각 별도 문서로 분리 저장
- [ ] 기존 문서와 주제가 겹치면 병합(update), 아니면 신규 생성(create)
- [ ] 저장된 문서에 제목/태그/요약 자동 생성
- [ ] 저장 완료 메시지가 채팅에 표시
- [ ] 여러 드래프트 연속 저장 시 순서 보장 (앞선 저장 결과가 다음에 반영)

**Save Queue UI** *(미구현)*
- [ ] 저장 진행 중 → 플로팅 위젯에 상태 표시
- [ ] 저장 성공/실패 결과 표시
- [ ] 저장 중에도 새로운 입력 가능 (non-blocking)

## 5. Pull-out

**검색 + 답변**
- [ ] 질문 입력 → 저장된 문서에서 검색 → 답변 생성
- [ ] 답변이 스트리밍으로 표시
- [ ] 답변은 저장된 문서 기반만 사용 (LLM 일반 지식 미사용)

**엣지 케이스**
- [ ] 관련 문서 없음 → "관련 문서가 없습니다" 메시지 (LLM 호출 없이)
- [ ] 저장 직후 아직 후처리 안 된 문서 → 텍스트 검색으로 검색 가능
- [ ] 저장 + 후처리 완료된 문서 → 의미 검색 + 그래프 검색으로 검색 가능

**소스 표시** *(미구현)*
- [ ] 답변과 함께 출처 문서 링크 표시
