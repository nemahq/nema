# QA Bug Report (2026-03-25)

> QA 체크리스트 기반 전수 점검 결과. 이 PR(#143)에서 수정한 항목은 제외.

---

## Put-in (드래프트)

- **수정 요청 시 이전 맥락 미반영**: 드래프트 수정 요청 시 이전 대화/본문 맥락 없이 마지막 입력만 기반으로 재생성됨.
- **드래프트 탭 Suspense 범위**: 새로고침 시 드래프트 탭 레이아웃이 먼저 나오지 않고 전체가 로딩 상태. Suspense 범위를 좁혀서 탭 셸은 즉시 렌더, 콘텐츠만 로딩되도록 개선 필요.

## Pull-out (질문)

- **질문 기능 동작 안 함**: pull-out 모드로 질문 전송 시 응답이 오지 않음. 새 세션에서도 동일.

## 저장 (Save Queue)

- **`{titles}` interpolation 미동작**: 저장 완료 시 세션 로그에 `{titles} 저장 완료`로 표시. 번역 키의 변수 치환이 안 됨.
- **Save Queue Panel 스크롤**: 대기 아이템이 많을 때 패널이 무한 확장됨. 내부 스크롤 영역 추가 + 최대 3개 표시로 제한 필요.

## 에러 처리

- **LLM 응답 실패 시 피드백 없음**: 네트워크 차단 상태에서 메시지 전송 시 에러 메시지 없이 동일 요청을 무한 재시도.
- **네트워크 끊김 시 ErrorBoundary 미표시**: Offline 상태에서 스켈레톤만 보이고 ErrorBoundary 폴백 화면으로 전환되지 않음.

## UX

- **번역 키 누락 점검**: 앱 전체에서 번역 키가 그대로 노출되는 곳이 있는지 전수 점검 필요.

## QA 미체크 항목 (기능 미구현 또는 확인 불가)

- 취소된 드래프트 열람 / 재수정 / 수정 이력 / 이전 버전 선택 / 유사 문서 힌트 (드래프트 이력 기능 미구현)
- 저장 직후 텍스트 검색 가능 여부 (문서 목록 뷰 없음)
- 답변과 함께 출처 문서 링크 표시 (소스 표시 미구현)
- 여러 주제 분리 저장 / 병합·신규 판단 / 제목·태그·요약 자동 생성 (문서 목록 뷰 없어 확인 불가)
- Rate limit 초과 안내 (로컬 재현 불가)
- 서버 에러 메시지 한국어 표시 (에러 재현 필요)
