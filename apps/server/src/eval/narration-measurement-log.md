# 해설 엔진 측정 일지

> 해설(③ 꺼내기 8단계) 평가의 라운드별 기록 — 무엇을 바꿨고, 숫자가 어떻게 움직였고, 무엇을 발견했나.
> 측정 대상 = 제품과 동일한 `prompts/narration.ts` + `services/narration.ts`의 `buildNarrationUserMessage`(같은 입력 직렬화). 측정 모델은 `EVAL_LLM_MODEL`로 교체 가능 — 회차별로 명시한다.
> raw 결과(마커 없는 문장 전수)는 같은 폴더의 `results-narration-markers-*.json`(gitignore, 재실행으로 재생성).

## 측정 #1 — 2026-06-23 · 마커 누락률 첫 가동 (NEM-168 태스크 9, 측정 모델 `gemini-3.5-flash`)

**바꾼 것**: 엔진 불변. 새 러너 `run-narration-markers.ts` + 시드 `narration-marker-seed.ts`. 해설 산문이 문장마다 `[s:<id>]` 근거 마커를 다는지(narration 규칙 2), 안 단 문장 비율을 순수 기계적으로 잰다 — judge 불필요. §3가 "해설의 유일한 자동 신호"로 정한 충실성 누수의 싼 조기경보다. 분모 = 답변가능 묶음만(근거 있음); "근거 없음" 인정(규칙 3)은 마커 없는 게 정상이라 시험지에서 뺀다(그 신호는 `eval-narration.ts` 수동 눈검사 몫). 시드 4묶음은 "흘림 유발형"(진술 다수·관계 마커 체인·타입 혼합·충돌 표식)으로 골랐다 — 짧고 뻔한 입력은 항상 0%라 가짜 안심을 준다. 묶음당 5회(단발 금지, 측정 #5·#7 결).

| 묶음                      | 모양                      | 평균 누락률        |
| ------------------------- | ------------------------- | ------------------ |
| channel-many-claims       | 주장 6개 단일 주제        | 0                  |
| payment-relation-chain    | 밀어냄(묶음 밖 참조)+해소 | 0                  |
| sprint-mixed-types        | 주장·질문·할 일 혼합      | 0                  |
| onboarding-conflict-dense | 충돌 표식 + 진술 6개      | **0.04**           |
| **전체 (micro)**          | 67문장 / 20런             | **0.015** (누락 1) |

**발견**:

- **baseline 거의 0** — 67문장 중 마커 없는 문장 1개(1.5%). flash는 진술들을 연결어로 한 문장에 묶어 마커를 빽빽이 단다. 건강한 천장이라, 이 신호의 값은 "0에서 벗어나는 순간"을 싸게 잡는 데 있다.
- **유일한 누락 = 충돌을 틀로 소개한 문장**. `onboarding-conflict-dense` 1런에서 "멘토 지정 방식에 대해서는 상충하는 기록이 존재합니다."가 마커 없이 나왔다 — 충돌 끝점(ob3·ob4)을 산문으로 풀며 태그를 흘린 것. 충돌 표식 묶음을 일부러 넣은 이유가 이 누수였고, 5회 중 1회 재현됐다. **관계를 산문화할 때가 마커 누수 1순위 자리.**
- **지표는 문장 단위지 claim 단위가 아니다** — 한 문장이 진술 2개를 마커 2개로 덮으면 정상으로 친다. "한 문장 안에서 일부 claim만 태그"는 못 잡는다(그건 충실성 judge·사람 몫, §3). 이 러너는 의도대로 *문장에 마커가 0개인 경우*만 싸게 거른다.

**주의 (모델 종속)**: 이 0~1.5%는 `gemini-3.5-flash` 스냅샷이다. 마커 다는 행동은 모델 종속이라(llm-model-map "하지 말 것"), prod 기준 확정은 `narrate` tier 모델(gpt-5)로 재측정 후 고정한다. 지금은 자(러너)가 작동함을 보인 첫 컷.

**다음**: 충돌·밀어냄을 산문화하는 묶음을 늘려 "관계 산문화 시 누수율"을 따로 본다. 정식 해설 평가셋(충실성 judge 포함)은 narration-design 9장 후속.
