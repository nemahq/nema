## 측정 #3 — 2026-06-12 · 프롬프트 v3~v5 반복 + 심판 보정 (만족선 도달)

- *프롬프트 v5*: 규칙 추가 대신 **작동 예시(few-shot) 1개**로 모양을 통째로 제시(평가 글과 다른 도메인) + 이유 형태는 결정당 최대 1개 → **0.93**
- *심판 보정* (표본 검사 대행): 매칭 완화(보고 형식·자명한 한정어·질문/미결 표현 차이 무시), 원자성에 "이유 연결 진술은 한 단위" 예외, 자기완결에 1인칭 허용
- *골든 보정*: 기준 #8 이전 결의 4건 정비 — transcript s4·s6, braindump s5 분리, weekly에 "리팩토링 진행 중" 추가 (골든 36개)

**알려진 잔여** (다음 라운드 후보):

- 회의 메모의 '이유 선택' 1건: 원문에 근거 둘("급하다", "한 달 걸린다니까")이 걸려 있어 엔진이 04 본보기와 다른 쪽을 주 이유로 고름 — 방어 가능한 대안 독해. 실데이터에서 패턴이 반복되면 그때 기준화.
- smalltalk의 "내일부터 다시 달려야지"가 5회 중 4회 추출됨(0~1개 경계 깜빡임) — 골든 노트의 노이즈 경계 케이스 그대로.
- 시간 한정 질의(q13)의 부분 실패 — 임베딩의 시간 약점, 다중 쿼리 추출(retrieval-design 보정 레버) 검토 거리.

**부수 발견 (제품 이슈)**: gpt-5 추출이 긴 글에서 **제품 기본 타임아웃 30초를 자주 초과** — worker도 같은 값이라 실서비스에서 긴 글 추출이 재시도 소진으로 영구 실패할 수 있다. 러너는 120초로 우회했고, 제품 타임아웃 적정값은 별도 이슈로 다룰 것.
