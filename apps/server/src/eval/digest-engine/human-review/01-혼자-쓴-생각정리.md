## 1. [decision] 온보딩 자동화 아이템 우선 탐색

- **situation**: 창업 아이템 후보 중 온보딩 자동화와 내부 문서 버전관리 중 우선순위 결정
- **choice**: 온보딩 자동화 문제 해결을 위한 인터뷰 진행
- **reason**: 온보딩 자동화가 문제 강도 및 책임 소재 측면에서 더 명확하여 우선순위가 높음
- **tradeoff**: 
  - 문서 버전관리에 투입할 리소스 확보 어려움
- **alternatives**: 
  - 내부 문서 버전관리 아이템 우선 탐색

## 2. [decision] 초기 서비스 제공 방식 결정

- **situation**: 초기 도입 장벽을 낮추기 위한 서비스 모델 결정
- **choice**: 셀프서비스 형태의 얇은 기능으로 시작
- **reason**: 도입 장벽을 낮추는 것이 기능 추가보다 초기 성장에 더 효과적이라는 사례 확인
- **tradeoff**: 
  - 풀서비스 대비 제공 가능한 기능 범위 제한
- **alternatives**: 
  - 처음부터 풀서비스 형태로 개발

## 3. [pending] 내부 문서 버전관리 아이템의 책임 소재 확인

- **question**: 내부 문서 버전관리 문제를 조직 내 누가 주도적으로 책임지고 있는가
- **background**: 문제의 강도와 대체 불가능성은 높으나 책임 소재가 불분명하여 의사결정 보류
- **branches**: 
  - 특정 직무가 책임지고 있다면 추진
  - 책임 소재가 불분명하다면 포기
- **resolutionCondition**: 다음 인터뷰를 통해 내부 책임자 확인

## 4. [learning] 초기 성장 동력에 대한 교훈

- **finding**: 초기 B2B 서비스 성장에서 기능을 늘리는 것보다 도입 장벽을 낮추는 것이 더 효과적이다
- **evidence**: 대기업 대상 풀서비스에서 중소기업 대상 셀프서비스로 피봇하여 성장한 사례

## 5. [idea] 끌림(관심)을 창업 아이템 선정 지표로 활용

- **concept**: 개인적 고통이 없는 문제라도, 특정 아이템에 지속적으로 마음이 끌린다면 그것을 중요한 신호로 간주함
- **background**: 돈은 될 것 같지만 끌리지 않는 후보들과 대조되는 온보딩 자동화 아이템에 대한 지속적인 관심을 확인
- **branches**: 
  - 끌림이 있는 아이템 위주로 우선 탐색
  - 끌림과 시장성 간의 상관관계 검증

## 6. [assumption] 창업 후보 필터의 유효성

- **assumption**: 문제 강도, 책임 소재, 반복성, 대체 불가능성을 기준으로 후보를 필터링하는 것이 유효하다
- **evidence**: 직관적인 필터링을 통해 소상공인 정산, 회의록, 견적서 관리 등의 후보를 효율적으로 제외함
- **impact**: 잘못된 필터 기준일 경우 유망한 아이템을 조기에 제거하거나 부적합한 아이템에 시간을 낭비하게 됨
- **verificationCondition**: 인터뷰를 통해 필터가 실제로 시장의 문제점과 일치하는지 확인
