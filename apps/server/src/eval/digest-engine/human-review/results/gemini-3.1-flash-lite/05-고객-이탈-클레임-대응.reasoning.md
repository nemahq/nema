# 05-고객-이탈-클레임-대응 (reasoning)

digest count: 5

## [결정] 지연 현상 원인 파악 우선 결정

- **상황**: 통화 연결 초반 음성 지연 현상이 빈번하게 발생하여 고객 이탈이 증가하는 상황
- **선택**: 원인 파악을 확실히 마친 후 대응 방안을 결정하기로 함
- **이유**: 섣불리 솔루션을 교체하거나 대응할 경우 리스크가 크기 때문임
- **트레이드오프**: 
  - 문제 지속으로 인한 고객 이탈 방치
- **대안**: 
  - 현재 솔루션 즉시 교체
  - 원인 파악 없이 즉각적인 대응 조치 적용

> **판단 이유**: 세아(PM)가 리스크를 언급하며 원인 파악 후 대응을 결정했으므로 의사결정으로 분류함.

## [미결] 지연 문제의 원인 파악

- **질문**: 통화 초반 3~10초간 음성이 들리지 않는 문제의 근본 원인은 무엇인가?
- **배경**: 하루 통화의 약 25%에서 지연 현상이 재현되고 있으며, 특정 헤드셋 모델과의 연관성이 의심되는 상황임
- **선택지**: 
  - 서버 측 네트워크 지연
  - 특정 헤드셋 모델(HX-200)의 펌웨어 오류
  - 기타 장비 연결 설정 문제
- **확인 조건**: 원인 파악 및 펌웨어 분석이 완료되는 시점

> **판단 이유**: 도영이 아직 확실치 않다며 원인을 조사 중이라고 언급한 미결정 상태임.

## [미결] 진행 상황 공유 시점 확정

- **질문**: 원인 파악 진행 상황을 언제 공유할 것인가?
- **배경**: 민서가 진행 상황 공유 시점을 문의했으나 세아가 아직 정하지 못했다고 답함
- **확인 조건**: 내일 오전 회의

> **판단 이유**: 세아가 아직 정하지 못했고 내일 다시 말하겠다고 하여 현재 미결정 상태임.

## [학습] 통화 지연 현상 재현율 확인

- **발견**: 전체 통화의 약 25%에서 통화 연결 초반 3~4초간 음성 지연 현상이 발생함
- **근거**: 엔지니어 도영의 로그 분석 결과

> **판단 이유**: 도영이 로그 확인 후 사실로서 제시한 데이터임.

## [아이디어] 임시 우회 방안 검토

- **발상**: 원인 파악이 늦어질 경우 유선 전화 라우팅으로 우회하는 방안
- **배경**: 근본적인 해결 전이라도 급한 불을 끄기 위한 임시 대응 필요성

> **판단 이유**: 세아가 임시 방안으로 검토하기로 했다고 밝힌 아이디어임.

## 제외된 판단 (1개)

- "이번 주 안에 원인 못 찾으면 다른 솔루션으로 갈아탈 것" — 조건부 협박에 가까운 요구사항이며, 현재 확정된 실행 계획이 아니므로 제외함.
