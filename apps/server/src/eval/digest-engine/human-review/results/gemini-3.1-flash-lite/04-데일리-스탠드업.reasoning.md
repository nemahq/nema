# 04-데일리-스탠드업 (reasoning)

digest count: 4

## [결정] 결제 테스트 환경 유지

- **상황**: PG사 응답 이상으로 인해 결제 API 연동 테스트에 어려움이 있음.
- **선택**: 실제 계정 심사가 나올 때까지 샌드박스 계정을 사용하여 테스트를 진행하기로 함.
- **이유**: 실제 계정이 다음 주에나 제공될 것으로 예상되기 때문.

> **판단 이유**: 준이 문제 상황을 설명하고 향후 대응 방안을 결정한 것이므로 결정(Decision)으로 분류함.

## [미결] 디자인 시스템 작업 우선순위 결정

- **질문**: 다음 디자인 시스템 작업의 우선순위를 어떻게 설정할 것인가?
- **배경**: 현재 디자인 시스템 컴포넌트 3개 작업을 마친 상태이며, 이후 작업에 대해 재조정이 필요함.
- **확인 조건**: 오늘 오후 지훈과의 논의를 통해 결정될 예정.

> **판단 이유**: 라희가 우선순위 조정을 위해 별도의 회의를 계획하고 있어 미결정 상태로 분류함.

## [학습] 온보딩 퍼널 이탈 지점 확인

- **발견**: 온보딩 퍼널의 3단계에서 이탈자가 유독 많음.
- **근거**: 온보딩 퍼널 데이터 확인.

> **판단 이유**: 지훈이 데이터를 통해 사실을 확인했으므로 학습(Learning)으로 분류함.

## [아이디어] 온보딩 이탈 원인 가설

- **발상**: 온보딩 3단계 이탈의 원인은 UX 문제일 것임.
- **배경**: 온보딩 3단계에서 이탈이 빈번하게 발생하고 있으나 정확한 원인은 미상임.

> **판단 이유**: 지훈이 UX 문제일 것이라고 추측하고 있으나 확정되지 않은 가설이므로 아이디어로 분류함.

## 제외된 판단 (3개)

- "도현: 어제 배포한 검색 로직 이상 없음. 오늘은 이미지 OCR 쪽 마저 붙일 예정." — 업무 진행 상황 공유일 뿐, 별도의 의사결정이나 새로운 판단을 담고 있지 않음.
- "세아: 테스트 커버리지 늘리는 중, 특이사항 없음." — 일반적인 업무 보고이며 판단 사항이 없음.
- "도경: 인프라 쪽 특이사항 없음. CI 속도 개선은 계속 백로그에 있음." — 진행 상황 공유 및 상태 확인일 뿐 결정 사항이 아님.
