## [결정] 알림 배지 버그를 이번 스프린트 내 수정

- **상황**: 버그 발생 빈도와 심각도를 검토해야 했다.
- **선택**: 알림 배지 카운트 불일치 버그를 이번 스프린트 안에 수정한다.
- **이유**: 하루 약 40건이 발생하고, 한 번 발생하면 새로고침 전까지 잘못된 값이 계속 표시된다.

> **판단 이유**: 하윤이 발생 현황을 들은 뒤 이번 스프린트 내 수정하겠다고 명시했다.

## [결정] 버그 우선순위를 High로 유지

- **상황**: 버그의 심각도를 재검토해야 했다.
- **선택**: 이 이슈의 우선순위를 High로 유지한다.
- **이유**: 발생 시 새로고침 전까지 잘못된 배지 수가 계속 표시되어 사용자 체감 영향이 클 것으로 보였다.

> **판단 이유**: 하윤이 심각도 검토 후 우선순위를 그대로 High로 유지한다고 명시했다.

## [결정] 낙관적 배지 업데이트 제거

- **상황**: 낙관적 업데이트를 없앨지, 유지한 채 타이밍 버그만 수정할지 결정해야 했다.
- **선택**: 낙관적 업데이트를 제거하고 서버 응답 기준으로만 알림 배지를 갱신한다.
- **이유**: 사용자 입장에서는 잘못된 배지 수보다 약간 늦게 반응하는 것이 낫다는 디자인 의견을 반영했다.
- **트레이드오프**: 
  - 배지 반응이 약 0.5초 느려져 덜 즉각적으로 느껴질 수 있다.
- **대안**: 
  - 낙관적 업데이트를 유지하면서 타이밍 버그만 수정해 배지의 즉각적인 반응성을 유지한다.

> **판단 이유**: 재윤이 디자인 의견을 반영해 서버 응답만 신뢰하는 방식으로 하기로 했다고 확정했다.

## [미결] 알림 목록 API 페이지네이션 이슈의 별도 티켓 생성 여부

- **질문**: 알림 목록 API의 페이지네이션 처리 문제를 별도 티켓으로 만들지 결정해야 한다.
- **배경**: 수정 과정에서 페이지네이션 처리가 이상해 보였지만, 현재 이슈의 범위는 아닌 것으로 보인다.
- **선택지**: 
  - 별도 티켓을 생성한다.
  - 별도 티켓을 생성하지 않는다.

> **판단 이유**: 재윤이 별도 티켓을 만들지 아직 정하지 않았다고 명시했으므로 미결 질문이다.

## [학습] 알림 배지 수와 실제 미확인 항목 수의 불일치 재현

- **발견**: 사이드바의 알림 배지 수가 실제 미확인 항목 수와 다르게 표시되는 현상이 재현되며, 새로고침하면 다시 맞는다.
- **근거**: 배지에는 5가 표시되지만 실제 미확인 항목은 2개인 사례가 재현됐다.

> **판단 이유**: 이슈 설명과 재윤의 '재현했습니다' 발언이 현상의 재현을 확인한다.

## [학습] 불일치 현상은 하루 약 40건 발생

- **발견**: 알림 배지 불일치 현상은 하루에 대략 40건 기록된다.
- **근거**: 로그에서 하루 약 40건이 확인됐다.

> **판단 이유**: 재윤이 로그를 근거로 발생 건수를 보고했으므로 확인된 운영 관찰로 분류했다.

## [학습] 수정 PR의 로컬 재현 시나리오 검증 통과

- **발견**: PR #1204는 로컬 재현 시나리오를 20회 실행했을 때 이상이 없었다.
- **근거**: 재윤이 로컬에서 재현 시나리오를 20번 돌려 확인했다고 보고했다.

> **판단 이유**: 구체적인 검증 횟수와 결과가 명시된 확인 사항이다.

## [가정] 낙관적 업데이트 타이밍이 불일치의 원인일 가능성

- **가설**: 클라이언트가 배지 수를 낙관적으로 증가시킨 뒤 서버의 실제 값으로 덮어써야 하는 타이밍이 누락되는 것이 원인일 수 있다.
- **근거**: 클라이언트의 낙관적 증가와 서버 응답 기반 갱신 흐름이 존재한다.
- **영향**: 원인이 아니라면 낙관적 업데이트 제거 외에 추가 원인 분석과 수정이 필요할 수 있다.
- **검증 조건**: 서버 응답 도착 및 배지 상태 갱신 타이밍을 추적해 누락 여부를 확인한다.

> **판단 이유**: 재윤이 '원인은 이거 같은데 확실친 않습니다'라고 원인을 추정했으므로, 미검증 사실에 대한 가정이다.

## [가정] 불일치가 발생하면 사용자 체감 영향이 클 가능성

- **가설**: 발생 빈도는 활성 사용자 대비 크지 않더라도, 한 번 발생하면 새로고침 전까지 잘못된 값이 유지되어 사용자 체감 영향은 클 수 있다.
- **근거**: 불일치가 새로고침 전까지 계속 표시된다고 보고됐다.
- **영향**: 체감 영향이 낮다면 우선순위나 수정 시급성 판단이 달라질 수 있다.
- **검증 조건**: 사용자 피드백이나 영향 지표로 실제 체감 영향을 확인한다.

> **판단 이유**: 재윤이 '체감은 클 것 같아요'라고 영향도를 추정했으며, 확정된 측정 결과로 말하지 않았다.

## [가정] 알림 목록 API 페이지네이션 처리 이상 가능성

- **가설**: 알림 목록 API의 페이지네이션 처리에 문제가 있을 수 있다.
- **근거**: 수정 과정에서 페이지네이션 처리가 이상하게 보였다는 관찰이 있었다.
- **영향**: 문제가 확인되면 현재 배지 이슈와 별도로 API 페이지네이션을 수정해야 할 수 있다.
- **검증 조건**: 페이지네이션 동작을 재현·검증해 오류 여부를 확인한다.

> **판단 이유**: 재윤이 페이지네이션 처리가 '좀 이상하게 되어 있던데'라고 말했지만 확정하지 않았으므로 가정으로 분류했다.
