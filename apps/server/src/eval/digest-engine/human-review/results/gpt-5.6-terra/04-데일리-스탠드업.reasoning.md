# 04-데일리-스탠드업 (reasoning)

digest count: 5

## [결정] PG 연동 테스트를 샌드박스 계정으로 계속 진행

- **상황**: PG사 응답이 계속 비정상적으로 와 실제 계정 연동 테스트를 진행하기 어려운 상황이었다.
- **선택**: 실제 계정 심사가 나올 때까지 PG 연동 테스트는 샌드박스 계정으로 계속 진행하기로 했다.
- **이유**: 실제 계정은 다음 주에나 나올 것으로 보인다.
- **대안**: 
  - 실제 계정으로 테스트 진행 — 실제 계정 심사가 아직 나오지 않았고, 다음 주에나 나올 것으로 보인다.

> **판단 이유**: PG 응답 문제와 실제 계정 발급 지연 사이에서 테스트 환경을 정해 '계속 테스트하기로 함'이라고 명시한 결정이다.

## [미결] 디자인 시스템 이후 작업 우선순위 재조정

- **질문**: 디자인 시스템 컴포넌트 3개를 마친 뒤의 다음 작업 우선순위를 어떻게 정할지 결정해야 한다.
- **배경**: 라희가 다음 작업의 우선순위를 다시 맞춰야 할 것 같다고 했다.
- **확인 조건**: 오늘 오후 지훈과 별도로 논의하기로 했다.

> **판단 이유**: 다음 작업의 우선순위를 아직 정하지 않았으며, 이를 논의할 예정이라고만 되어 있어 미결정 사안이다.

## [학습] 배포한 검색 로직에 이상 없음

- **발견**: 어제 배포한 검색 로직에는 이상이 없다.

> **판단 이유**: 도현이 배포 후 검색 로직에 '이상 없음'이라고 보고했으므로, 확인된 상태에 관한 학습이다.

## [학습] 온보딩 퍼널 3단계의 이탈이 특히 많음

- **발견**: 온보딩 퍼널 데이터에서 3단계의 이탈이 유독 많다.
- **근거**: 온보딩 퍼널 데이터를 확인한 결과다.

> **판단 이유**: 지훈이 퍼널 데이터를 근거로 3단계 이탈이 많다는 관찰 결과를 보고했다.

## [가정] 온보딩 3단계 이탈의 원인은 UX 문제일 가능성

- **가설**: 온보딩 퍼널 3단계에서 이탈이 많은 원인은 UX 문제일 것으로 보고 있다.
- **근거**: 3단계에서 이탈이 유독 많다는 퍼널 데이터 관찰.
- **검증 조건**: 정확한 원인을 확인할 때.

> **판단 이유**: 정확한 원인은 아직 모른다고 한 뒤 UX 문제일 것이라고 추정했으므로, 검증되지 않은 원인 가설이다.

## 제외된 판단 (5개)

- "도현이 오늘 이미지 OCR 작업을 마저 붙일 예정이라고 함." — 단순 작업 계획이며, 지속적으로 되짚을 선택이나 판단이 제시되지 않았다.
- "세아가 테스트 커버리지를 늘리는 중이며 특이사항이 없다고 함." — 진행 상황 보고와 단순 상태 보고로, 별도의 판단이 아니다.
- "라희가 디자인 시스템 컴포넌트 3개를 마무리함." — 완료된 작업 보고이며, 우선순위 미결정 사항은 별도 pending으로 기록했다.
- "인프라 쪽 특이사항 없음." — 단순 상태 보고로, 판단이나 확인된 새 지식으로 기록할 만한 구체성이 없다.
- "CI 속도 개선은 계속 백로그에 있음." — 백로그 상태만 언급되었고, 이를 유지하거나 미루기로 한 결정의 주체·근거·대안이 드러나지 않아 판단 유형이 불명확하다.
