## [결정] 오늘 이미지 OCR 연동 작업 진행

- **선택**: 오늘 이미지 OCR 쪽 연동 작업을 마저 진행하기로 했다.

> **판단 이유**: 도현이 오늘 OCR 작업을 마저 붙일 예정이라고 명시해, 향후 작업 방향이 정해진 것으로 보았다.

## [결정] 실계정 심사 전까지 샌드박스 계정으로 테스트 지속

- **상황**: 결제 API 연동 중 PG사 응답이 계속 이상하게 오는 상황이다.
- **선택**: 실제 계정 심사 결과가 나올 때까지 샌드박스 계정으로 계속 테스트하기로 했다.
- **이유**: 실제 계정 심사 결과가 아직 나오지 않았기 때문이다.

> **판단 이유**: 준이 '계속 테스트하기로 함'이라고 명시한 결정이다.

## [결정] 디자인 시스템 우선순위를 지훈과 별도 논의

- **상황**: 디자인 시스템 컴포넌트 3개를 마무리한 뒤 다음 작업의 우선순위를 재조정할 필요가 생겼다.
- **선택**: 오늘 오후 지훈과 별도로 이야기해 다음 작업의 우선순위를 다시 맞추기로 했다.

> **판단 이유**: 라희가 오늘 오후 별도 논의를 하기로 했다고 명시했으므로, 우선순위 자체의 미결 상태와 별개로 논의 일정은 결정으로 기록했다.

## [결정] CI 속도 개선을 백로그에 유지

- **선택**: CI 속도 개선 작업을 계속 백로그에 두기로 했다.

> **판단 이유**: 도경이 CI 속도 개선이 계속 백로그에 있다고 말해, 해당 작업의 현재 처리 방침으로 분류했다.

## [미결] 디자인 시스템 다음 작업의 우선순위 재조정

- **질문**: 디자인 시스템의 다음 작업 우선순위를 어떻게 다시 맞출 것인가?
- **배경**: 컴포넌트 3개를 마무리한 뒤 다음 작업의 우선순위 조정이 필요해졌다.
- **확인 조건**: 오늘 오후 지훈과의 별도 논의

> **판단 이유**: 라희가 우선순위를 다시 맞춰야 한다고 했지만 구체적인 결과는 제시하지 않아 미결 질문으로 분류했다.

## [미결] 온보딩 3단계 이탈의 정확한 원인

- **질문**: 온보딩 퍼널 3단계에서 이탈이 유독 많은 정확한 원인은 무엇인가?
- **배경**: 온보딩 퍼널 데이터에서 3단계 이탈이 유독 많게 나타났다.

> **판단 이유**: 지훈이 정확한 원인을 아직 모른다고 명시했으므로 해결되지 않은 질문이다.

## [학습] 배포한 검색 로직에 이상 없음

- **발견**: 어제 배포한 검색 로직에는 이상이 없다.

> **판단 이유**: 도현이 배포한 검색 로직에 이상이 없다고 현황을 확인했다.

## [학습] PG사 응답이 지속적으로 비정상적임

- **발견**: 결제 API 연동 중 PG사 응답이 계속 이상하게 오고 있다.

> **판단 이유**: 준이 API 연동 과정에서 반복되는 PG사 응답 이상을 보고한 사실 확인으로 분류했다.

## [학습] 디자인 시스템 컴포넌트 3개 마무리

- **발견**: 디자인 시스템 컴포넌트 3개를 마무리했다.

> **판단 이유**: 라희가 완료한 작업 수를 명시적으로 보고했다.

## [학습] 온보딩 3단계 이탈이 유독 많음

- **발견**: 온보딩 퍼널에서 3단계 이탈이 유독 많다.
- **근거**: 온보딩 퍼널 데이터

> **판단 이유**: 지훈이 퍼널 데이터를 근거로 3단계 이탈이 많다는 관찰을 확인했다.

## [가정] 실제 계정 심사는 다음 주에 나올 것으로 예상

- **가설**: 실제 계정 심사 결과는 다음 주에나 나올 것으로 보인다.
- **영향**: 그때까지 샌드박스 계정으로 테스트를 계속하게 된다.
- **검증 조건**: 실제 계정 심사 결과가 나오는 시점

> **판단 이유**: 준이 실제 계정이 다음 주에나 나올 '것 같다'고 불확실한 미래 상태를 추정했다.

## [가정] 온보딩 3단계 이탈은 UX 문제일 가능성

- **가설**: 온보딩 3단계의 높은 이탈은 UX 문제일 것이라고 보고 있다.
- **검증 조건**: 이탈 원인에 대한 정확한 분석

> **판단 이유**: 지훈이 정확한 원인은 모른다고 하면서도 UX 문제라고 보고 있어, 검증되지 않은 원인 가설로 분류했다.

## 제외된 판단 (3개)

- "세아가 테스트 커버리지를 늘리는 중이라고 보고함" — 진행 중인 작업 상태만 제시되어 있으며, 완료된 판단·새 제안·미결 질문으로 명확히 분류할 내용이 아니다.
- "세아의 '특이사항 없음'" — 구체적인 대상이나 확인 내용이 없는 포괄적 상태 보고라 별도 판단으로 기록하지 않았다.
- "도경의 '인프라 쪽 특이사항 없음'" — 구체적인 대상이나 확인 내용이 없는 포괄적 상태 보고라 별도 판단으로 기록하지 않았다.
