# 09-한영-혼용-업무-메모 (reasoning)

digest count: 5

## 원문 제목

온보딩·배포·가격 실험 및 분기 목표 관련 업무 메모

> **판단 이유**: 메모는 온보딩 이탈 개선, 배포 파이프라인, 가격 페이지 실험, 팀의 분기 목표라는 여러 업무 주제를 함께 다룬다. 특정 판단 하나가 아니라 전체 주제를 포괄하도록 제목을 정했다.

## [결정] 온보딩 3단계 이탈 대응의 우선순위 조정

- **상황**: 온보딩 flow의 3단계 이탈률이 계속 높게 나타났고, retention 팀으로부터 tooltip 카피가 혼란스럽다는 피드백이 많았다는 이야기를 들었다.
- **선택**: 이번 주에는 tooltip 카피를 먼저 수정하고, 구조적 변경은 다음 스프린트로 미룬다.
- **이유**: 높은 이탈률과 confusing한 tooltip 카피에 대한 피드백이 있었기 때문이다.
- **트레이드오프**: 
  - 구조적 변경은 다음 스프린트까지 지연된다.

> **판단 이유**: 온보딩 이탈 문제에 대해 카피 수정과 구조적 변경의 시행 시점을 정했으므로 결정이다. 이탈 현상과 retention 팀 피드백이 해당 우선순위 결정의 배경과 이유로 제시됐다.

## [결정] 배포 시 설정 버전 명시

- **상황**: 배포 파이프라인에서 caching 문제가 발생했다.
- **선택**: 앞으로 배포마다 config version을 명시적으로 지정한다.
- **이유**: 문제의 근본 원인이 stale config를 참조한 것이었기 때문이다.

> **판단 이유**: 캐싱 문제 재발 방지를 위해 앞으로의 배포 방식에 대한 방침을 정했으므로 결정이다. stale config 참조가 원인이라는 확인이 이 선택의 이유로 연결된다.

## [미결] 가격 페이지 A/B 테스트 결과 해석

- **질문**: 가격 페이지 A/B 테스트가 아직 유의미하지 않은 이유가 표본 수 부족인지, 실제 효과가 없는 것인지 판단해야 한다.
- **배경**: 현재 A/B 테스트 결과는 아직 statistical significance가 나오지 않았다.
- **선택지**: 
  - 표본 수가 부족하다
  - 실제 효과가 없다
- **확인 조건**: 다음 주까지 테스트를 더 돌려본 뒤 판단한다.

> **판단 이유**: 유의미하지 않은 실험 결과의 원인이 두 가능성 사이에서 아직 결론 나지 않았고, 다음 주 추가 실험 후 판단하기로 했으므로 미결 사항이다.

## [미결] 이번 분기 팀 목표의 우선순위 정렬

- **질문**: 이번 분기 팀 목표를 growth와 retention 중 어디에 둘지 다시 정렬할 필요가 있는지 결정해야 한다.
- **배경**: 팀 내부에서 이번 분기 목표가 growth인지 retention인지 다시 align해야 한다는 의견이 나왔다.
- **선택지**: 
  - Growth를 이번 분기 목표로 둔다
  - Retention을 이번 분기 목표로 둔다
- **확인 조건**: 다음 주 팀 미팅에서 다시 논의한다.

> **판단 이유**: growth와 retention 중 분기 목표의 우선순위를 어떻게 둘지에 대해 아직 결론이 나지 않았으며, 다음 주 회의에서 재논의하기로 했다.

## [학습] 배포 캐싱 문제의 근본 원인 확인

- **발견**: 배포 파이프라인의 caching 문제는 stale config를 참조한 것이 근본 원인이었다.

> **판단 이유**: 메모가 caching issue의 root cause를 stale config 참조라고 단정적으로 기록하므로, 확인된 사실로 분류했다.

## 제외된 판단 (2개)

- "deploy pipeline의 caching issue를 fix했음" — 이미 수행 완료된 조치의 상태 보고이며, 향후 방침인 config version 명시 결정과 별개로 왜 그렇게 했는지 되물을 지속적 판단이 아니다.
- "새로 온 인턴 온보딩 문서 정리 끝. 별다른 이슈 없음." — 완료된 작업 및 상태 보고만 포함되어 있으며, 재검토할 판단이나 선택이 제시되지 않았다.
