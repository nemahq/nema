# 09-한영-혼용-업무-메모 (reasoning)

digest count: 4

## [결정] 온보딩 3단계 이탈 대응은 카피 수정부터 진행

- **상황**: 온보딩 플로우의 3단계 이탈률이 계속 높게 나타났다.
- **선택**: 이번 주에는 tooltip 카피를 먼저 수정하고, 구조 변경은 다음 스프린트로 미룬다.
- **이유**: Retention 팀 피드백에서 해당 tooltip 카피가 혼란스럽다는 의견이 많았다.
- **트레이드오프**: 
  - 구조 변경 적용은 다음 스프린트까지 지연된다.

> **판단 이유**: 높은 3단계 이탈에 어떻게 대응할지를 정했고, 즉시 카피를 수정한 뒤 구조 변경을 미루는 실행 순서까지 확정했다.

## [결정] 배포 시 설정 버전을 명시적으로 지정

- **상황**: 배포 파이프라인에서 캐싱 이슈가 발생했다.
- **선택**: 앞으로 배포할 때마다 config version을 명시적으로 지정한다.
- **이유**: 원인이 오래된 config를 참조하는 것이었기 때문이다.

> **판단 이유**: 캐싱 이슈의 원인에 대응해 앞으로의 배포 설정 방식을 정한 지속적인 운영 결정이다.

## [미결] Pricing 페이지 A/B 테스트 결과 해석

- **질문**: 현재 유의미하지 않은 A/B 테스트 결과가 표본 부족 때문인지, 실제 효과가 없는 것인지 판단해야 한다.
- **배경**: Pricing 페이지 A/B 테스트는 아직 통계적으로 유의미한 결과가 나오지 않았다.
- **선택지**: 
  - 표본 크기가 부족하다
  - 실제 효과가 없다
- **확인 조건**: 다음 주까지 테스트를 더 진행한 뒤 판단한다.

> **판단 이유**: 결과가 유의미하지 않은 이유와 그에 따른 결론을 아직 정하지 않았으며, 추가 테스트 후 판단하기로 했다.

## [미결] 이번 분기 목표를 Growth와 Retention 중 어디에 둘지 정렬

- **질문**: 이번 분기 팀의 목표가 growth인지 retention인지 다시 정렬해야 한다.
- **배경**: 팀 내부에서 목표 우선순위를 다시 맞춰야 한다는 의견이 나왔다.
- **선택지**: 
  - Growth를 이번 분기 목표로 둔다
  - Retention을 이번 분기 목표로 둔다

> **판단 이유**: Growth와 retention 중 어느 쪽을 분기 목표로 삼을지 논의가 제기됐지만 아직 결론이 나지 않았다.

## 겹쳐서 뺀 다이제스트 (1개)

### [학습] 배포 캐싱 이슈의 원인

- **발견**: 배포 파이프라인의 캐싱 이슈는 오래된 config를 참조한 것이 원인이었다.

> **담고 있다는 쪽**: [결정] 배포 시 설정 버전을 명시적으로 지정
> **그쪽 `reason`(이유)**: 원인이 오래된 config를 참조하는 것이었기 때문이다.
> **판정 이유**: Both state that the deployment caching issue was caused by referencing an outdated config.

## 제외된 판단 (2개)

- "캐싱 이슈를 수정했다." — 수정 완료는 일회성 작업 상태이며, 원인에 대한 학습과 향후 config version 지정 결정은 별도 digest로 기록했다.
- "새 인턴의 온보딩 문서 정리를 끝냈고 별다른 이슈가 없다." — 완료된 작업 및 상태 보고일 뿐, 나중에 왜 그렇게 했는지를 물을 판단을 포함하지 않는다.
