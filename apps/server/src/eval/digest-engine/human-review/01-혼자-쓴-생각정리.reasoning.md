# 01-혼자-쓴-생각정리 (reasoning)

digest count: 7

## [decision] 창업 후보군 선별 필터 설정

- **choice**: 문제 강도, 책임 소재, 반복성, 대체 불가능성을 기준으로 필터링 적용
- **situation**: 창업 문제 탐색 과정에서 수많은 후보군을 효율적으로 거르기 위해 기준이 필요함
- **reason**: 필터링을 통해 시간과 자원을 집중할 유망한 후보를 선정하기 위함
- **tradeoff**: 
  - 필터 기준이 엄격하여 잠재적 기회 요인을 놓칠 수 있음
  - 지나치게 논리적인 필터링으로 직관적인 영감을 배제할 가능성
- **alternatives**: 
  - 모든 후보를 동등하게 인터뷰
  - 시장 규모만 보고 선정
- **reasoning**: 노트 상단에서 문제 탐색을 위해 현재 사용하는 4가지 기준을 명확히 정의하고 있습니다.

## [decision] 온보딩 자동화 분야 우선 집중

- **choice**: 온보딩 자동화 후보를 우선 탐색 대상으로 결정
- **situation**: 남은 후보(온보딩 자동화, 내부 문서 버전관리) 중 우선순위를 결정해야 함
- **reason**: 문제 강도와 책임 소재가 명확하여 즉각적인 검증이 가능하다고 판단함
- **tradeoff**: 
  - 문서 버전관리 분야의 강력한 대체 불가능성을 일단 포기함
- **alternatives**: 
  - 내부 문서 버전관리 분야에 우선 집중
  - 두 분야를 동시에 병행
- **reasoning**: 두 가지 후보를 비교 분석한 후, 문제 강도와 책임 소재가 확실한 온보딩 자동화를 먼저 파기로 결정했습니다.

## [decision] 초기 서비스 방향 설정

- **choice**: 풀서비스가 아닌 셀프서비스 형태로 가볍게 시작
- **situation**: B2B 서비스의 초기 도입 전략을 설정해야 함
- **reason**: 기능 확장보다 도입 장벽을 낮추는 것이 초기 성장에 유리하다는 참고 사례의 교훈을 적용
- **tradeoff**: 
  - 풀서비스에 비해 고객의 개별 요구사항 대응력이 떨어짐
- **alternatives**: 
  - 대기업 대상 풀서비스 모델
  - 맞춤형 컨설팅 결합 모델
- **reasoning**: 참고 사례를 통해 도입 장벽을 낮추는 셀프서비스 전략이 초기 단계에 적합함을 학습하고 이를 적용하기로 결정했습니다.

## [pending] 내부 문서 버전관리의 책임 소재 불분명함

- **question**: 내부 문서 버전관리 문제의 핵심 책임자가 누구인지 확인해야 함
- **background**: 대체 불가능성은 높으나, 내부에서 누가 이 문제를 주도적으로 해결해야 하는지 파악되지 않음
- **branches**: 
  - 특정 직무(예: PM)가 책임자로 확인됨
  - 책임 소재가 불분명하여 조직 내에서 우선순위가 낮음
- **resolutionCondition**: 다음 사용자 인터뷰를 통해 담당자 여부 확인
- **reasoning**: 내부 문서 버전관리는 대체 불가능성이 높지만 책임 소재가 애매하여 결론을 내리지 못하고 향후 인터뷰를 통해 확인하기로 했습니다.

## [learning] 도입 장벽 감소의 중요성

- **finding**: 기능을 더 얹는 것보다 초기 도입 장벽을 낮추는 것이 초기 성장에는 훨씬 효과적임
- **evidence**: B2B 툴 사례에서 풀서비스로 시작했다가 셀프서비스로 피봇한 후 성장 곡선이 꺾인 경험담
- **reasoning**: 성공 사례 분석을 통해 서비스 초기 전략에 대한 교훈을 얻은 사례입니다.

## [idea] 창업 아이템 선택 시 직관적 끌림의 의미

- **concept**: 단순한 논리적 지표 외에도 본인의 '끌림'이라는 감정적 신호가 중요한 선택 기준이 될 수 있음
- **background**: 온보딩 자동화 아이템에 대한 지속적인 내적 끌림을 발견함
- **branches**: 
  - 끌림이 있는 분야는 해결 과정에서의 동기부여가 강함
  - 논리적 타당성만 쫓는 것보다 실행력 유지에 유리할 가능성
- **reasoning**: 본인의 심리적 반응을 신호로 인식하여 아이템 선정의 기준으로 고려하는 생각을 기록했습니다.

## [assumption] 경업금지 조항의 적용 범위

- **assumption**: 전 직장의 경업금지 조항(B2B 협업툴 영역)이 본인이 고려하는 아이템 선정에 법적/도의적 영향을 미침
- **evidence**: 퇴사 후 1년간 B2B 협업툴 영역이 금지 범위라는 인지
- **impact**: 해당 범주에 해당할 경우 창업 후보에서 즉시 제외됨
- **verificationCondition**: 실제 계약서 확인
- **reasoning**: 창업 후보 선별의 근간이 되는 제약 조건을 전제로 설정하고 있습니다.
