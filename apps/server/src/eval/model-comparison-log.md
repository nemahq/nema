# 모델 가성비 비교 측정 일지 (NEM-149)

`eval_runs` 테이블(쿼리용 이력)의 **사람용 서사 짝**. 테이블이 숫자를 시간·버전 축으로 쌓는다면, 이 문서는 각 회차의 맥락·해석·한계를 적는다. 표만으론 안 보이는 "왜 이 값인가, 어디까지 믿나"를 남긴다.

비교 대상은 워크로드 모델뿐(추출·관계·해설·초안). judge=Claude(sonnet-4-6)·임베딩=Voyage는 고정. 비용·지연은 실 SDK usage(추론 토큰 포함)로 잰다 — 추정 아님.

## 측정 #2 — 2026-06-24 · 전폭 1차 sweep (9종 × 4기능, staging 적재)

**무엇.** 단가 박힌 9종 × 4기능(추출·관계·해설·초안)을 `--persist`로 한 바퀴. 36행을 staging `eval_runs`에 적재(실패 0). 채점관(Claude) 2,167콜. 비용·지연은 최종, 품질은 잠정(쉬운 시험지).

**해석.**

- **gpt-5-mini = 점수 있는 둘의 가성비 스타** — 관계 0.875(2위)·추출 0.910을 $0.001~0.002에.
- **현 기준선 gpt-5는 관계에서 의외로 약함**(0.800 = 6위)이고 비쌈 — "한 모델로 전부"보다 기능별 특화가 데이터상 유리.

**해설·초안 (cost-only).** 둘 다 **gemini-3.1-flash-lite가 최저비용·최속**(해설 $0.0003·1.7s / 초안 $0.0005·1.3s) — 차순위의 수~수십 배 저렴. flash-lite 출력 **눈검사 1차 통과**: 해설은 근거 위에 머물고 빈 곳을 정상 인정(마커 0.333 누락은 "기록에 없음" 인정 1문장 = 허위경보), 초안은 입력 다항목을 누락·날조 없이 구조화(뜻 보존).

**한계.** 품질 절대값은 작은 코퍼스(진술 39·관계 14쌍) 위라 부풀려짐 — **모델 *상대 순위*는 믿되 절대 점수는 난도↑ 재측정 전까지 잠정**. 추출 ⚠️는 채점관도 Claude라 self-preference 가능(단 선두 추천이 다 비-Claude라 교차검증 불요). 해설·초안 품질은 자동채점 없어 눈검사 의존(flash-lite는 1차 통과, 본채택 전 더 봐야).

**다음.** 실제 배치는 코퍼스 강화(실데이터로 골든 키워 재 sweep)로 순위가 살아남는 걸 확인한 뒤, 가역 런타임 override→`TASK_DEFAULTS` 순으로.

## 측정 #1 — 2026-06-24 · 하니스 1차 검증 (잠정, NEM-168 §3 게이트 전)

**무엇.** 가성비 하니스 첫 end-to-end. 추출 스모크로 두 프로바이더(OpenAI·Anthropic)를 가로질러 배선·비용·지연·품질·박제를 검증. 모델 확정이 아니라 *기계가 도는지*를 본 회차.

**결과 (추출, eval 44e21048 · prompt 2f1d5f4b).**

| 모델 | 동작당 비용 | 지연 | 품질(잠정 합성) | 비고 |
| --- | --- | --- | --- | --- |
| gpt-5 | $0.017358 | 19.3s | 0.975 | golden F1 0.95 · 분류 1.0 |
| claude-haiku-4-5 | $0.004572 | 4.2s | 0.953 | ⚠️ self-preference |

**해석.** haiku가 **3.8배 싸고 4.6배 빠른데 품질은 거의 동급**(0.953 vs 0.975) — "싼 모델이 추출 standard 자리를 대체할 수 있나"의 첫 긍정 신호. 단 **추출 채점관이 Claude라 haiku 점수는 self-preference로 부풀려졌을 수 있다**(표의 ⚠️). 권위 판정은 §3 확정 + 채점관을 일시 교체한 교차검증 후로 미룬다.

**발견 둘.**
1. gpt-5 출력 토큰의 **83%가 추론 토큰**(call당 reasoning 1216 / output 1467). tiktoken 추정이었으면 이 비용을 통째로 놓쳐 ~1/6로 과소계상했다 — "실 usage 포착" 결정이 옳았음을 데이터가 증명.

**한계 (이 회차를 권위로 쓰면 안 되는 이유).** 잠정이다. 모델 2종·기능 1개(extract)·1회뿐. NEM-168 §3 게이트 전이라 모델 확정 안 함. 코퍼스는 진술 39개짜리 "쉬운 시험". 9종 전체 스윕 + 관계·해설·초안 + 교차검증은 게이트 후 권위 측정에서.
